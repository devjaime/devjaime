## 🔬 Current areas of research

### Coding agents

I'm interested in how coding agents can move from simple code generation toward **goal-oriented engineering systems** capable of:

1. Understanding large repositories
2. Discovering relevant context
3. Using external tools
4. Planning changes
5. Modifying code
6. Running and validating tests
7. Measuring the quality and cost of execution

### Code intelligence

I'm experimenting with approaches that combine:

```text
AST → Code Graphs → Search → Retrieval → Agents
````

Tools and concepts I frequently explore include:

* AST / ast-grep
* Repository graph generation
* MCP
* CLI-based coding agents
* Structured code retrieval
* Semantic search
* Context optimization
* Multi-agent workflows

### Agent evaluation

I'm particularly interested in measuring:

```text
Task
  ↓
Agent
  ↓
Model + Context + Tools
  ↓
Execution
  ↓
Tests / Validation
  ↓
Tokens + Cost + Tool Calls + Outcome
```

Because evaluating an agent only by whether it eventually produced some code is not enough.
